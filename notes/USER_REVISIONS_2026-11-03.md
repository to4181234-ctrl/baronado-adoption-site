# 2026-11-03 사용자 수정안 반영

기준: 업로드한 5페이지 수정안 PDF, 팝업에서 강아지별 지정 문구를 제외한다는 후속 정정, Group 72.svg.
이 작업 이후 소스는 GitHub main을 기준으로 이어간다. 이전 10차 ZIP이나 46c2c38을 최신본으로 사용하지 않는다.
운영 주소: https://baronado-adoption-site-8sm2.vercel.app

## 반영 내용

- 상단 바로나도 로고를 제공된 47×9 SVG 원본으로 교체.
- 발견 팝업의 강아지별 지정 대사만 제거. 기본 등장 문구와 두 이동 선택지 유지. 픽셀 선택 화살표와 발견 효과 보완.
- 접종 여부의 중복 제목 제거, 상세 표의 그룹 경계 중복선 제거. 상주견 소개 전체 표시, 빈 상세 정보 제목과 메뉴 숨김.
- 도감 실루엣과 힌트 사이 간격 확보. 로그인 글씨 검정, MonaS12 Bold 적용.
- 카메라 권한 안내를 먼저 표시. 카메라 화면의 ‘수집한다’는 대화창을 닫고 촬영을 준비하며 목줄 버튼이 실제 촬영을 수행. 1:1 가이드와 목줄을 서로 다른 행에 배치. 음원 버튼 아이콘과 픽셀 선택 표시 반영.
- 카드 등장 및 터치 시 빛·효과음 재생. 재생 방법을 설명하는 불필요한 문구 제거. 카드 작성자 BY. 제거는 화면과 PNG 공통 모델에 적용.
- 공유 준비 중 공 모양 애니메이션 대신 원본 목줄 픽셀 이미지 사용.
- 재수집·배틀 선택 및 정렬 버튼의 임의 파란색 제거. 배틀 충돌·빛 효과와 좋아요 효과 보완.
- 기존 go_battles 저장 내역을 회원별로 조회·집계하여 도감에 강아지별 승·무·패 표시. 페이지 제한으로 기록이 누락되지 않도록 조회하며 새로운 DB 테이블이나 권한 변경은 추가하지 않음.
- 승인된 21개 MP3 원본 바이트 유지. HTML 음량 조정 외에 Web Audio로 작은 BGM과 획득 효과음의 재생 음량을 보정. Web Audio 미지원 시 일반 HTML 오디오 사용. 화면 닫힘·백그라운드·음소거 시 재생 정리. 카드 수집 완료 시 도감 BGM 복귀.

## 검증

- Node 테스트 69개 통과: 배틀 방향별 승패·무승부, 1,001건 조회, 회원 범위, 오류 처리, 오디오 연결 재사용·정리와 음량 보정 포함.
- Next.js 운영 빌드 통과. 승인 음원 21개 해시 확인 통과.
- 검토용 배포의 실제 브라우저에서 팝업 기본 문구만 출력, 선택 화살표 한 개 표시, 원본 로고, 상주견 소개 전체 표시·빈 상세 정보 숨김, 접종 제목 중복 제거, 표 그룹 경계선, 실루엣 간격, 검정 MonaS12 Bold 로그인 표시 확인.
- 동일한 백엔드 변경을 운영 배포에서 13개 API 검사로 확인: 임시 계정 로그인, 빈 전적, 카드 2장 발급, 대결 저장·UUID 재시도, 승무패 조회, 타 회원 기록 분리, 마지막 카드 삭제 시 전적 초기화, 계정 삭제.
- DB/Storage 최종 조회에서 검증용 회원·카드·배틀·사진 각각 0개 확인. 기존 자료는 수정하거나 삭제하지 않음.
- 배포된 로고 파일이 업로드한 SVG와 SHA-256 일치함을 확인.

## 실제 기기에서 남은 확인

실제 iPhone/Android의 카메라 영상·촬영·줌, Instagram 내부 브라우저의 미디어 동작과 실제 청취 음량은 이 원격 브라우저에서 검증하지 못했다. 브라우저가 첫 방문 자동 재생을 차단하면 첫 사용자 터치 시 재시도하며, 강제로 자동 재생을 보장하지 않는다. 모든 Figma 프레임의 픽셀 단위 일치를 전수 판정한 것은 아니다.
