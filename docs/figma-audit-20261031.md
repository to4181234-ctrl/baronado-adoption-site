1. `public/audio/meonggo/*.mp3` 실제 바이너리 21개는 **아직 GitHub 브랜치에 없음**. 준비 ZIP `MeongGO_Approved_MP3_Figma_Staging_20261031.zip`을 같은 경로로 복사해야 함.
2. `supabase/migrations/20261031_go_popup_account_preferences.sql`은 **아직 운영 DB에 적용하지 않음**. API `/api/go/settings`은 해당 마이그레이션 적용 후 테스트 필요.
3. Figma 전체 화면의 렌더링 대조, 모바일 브라우저 테스트, 로그인·API·카메라·배틀 실제 플로우 검증은 미완료. 코드 변경만으로 픽셀 정확도를 주장하지 않음.
4. 검토용 강아지별 대사 보드는 승인 완료 문구가 아님. 임의로 확정하지 않음.
5. Figma에 포함된 모든 사진·벡터 슬롯의 원본 로컬 파일 여부 및 화면 내 실제 렌더링 위치를 전수 검증할 것.

## 배포 전 확인할 음원 동작

- 앨범 열림 자체만으로 음악 재생하지 않음; 실제 사용자 동작 뒤에 ZIP BGM 실행
- 마이페이지·커뮤니티 등 비게임 동작 화면에서 임의 음악 실행하지 않음
- 카메라 시작 시 기존 도감 BGM 정지 후 카메라 BGM; 종료 시 복귀
- 배틀 카드 선택/해제/준비: ZIP `SFX_02/03/04`
- 0초 시작음, 0.5초 카드 등장, 1.4초 충돌음, 3초 후 승·무·패 결과음
- 교감 5초 무입력→측면 걷기, 눌렀을 때 2초 반응; 연속 탭/음소거 중복음 없음
- 카드 저장 실패 시 획득음 없음; 성공 1회, 카드 명시적 재터치만 재생
- 7일 숨김 해제는 오늘 이미 봤던 팝업을 자동으로 다시 열지 않음
