# 멍멍GO 2.0 배포 후보: 실제 로컬 HTTP 통합 검증

2026-11-17 KST. 사용자 지시로 부족한 백업 확보는 생략. 운영배포·운영 SQL·운영 DB/Storage 수정은 하지 않았다.

- Next.js/eslint-config-next **16.4.6** 보안 패치. 최종 코드 기능 ON/OFF 빌드 모두 PASS.

## 발견하고 고친 문제

관리자 `newDraft`는 기존 공개 사진 경로를 복사한다. 수정안에서 사진을 교체할 때 이전 코드가 그 경로의 Storage 파일을 삭제해 **공개 중인 사진까지 사라지는 문제를 실제 업로드로 재현**했다. 수정 전 공개 사진 객체수1→0으로 검증 실패.

`removeUnusedDraftAssets`는 해당 수정안이 생성한 경로만 정리하고, 다른 asset의 참조가 남아 있거나 참조 확인에 실패하면 파일을 보존한다. PUT 교체와 PATCH 크롭 양쪽에 적용. 수정 후 동일한 실제 업로드·게시 테스트에서 기존 공개 객체1개 유지 PASS. 데이터 삭제는 모두 합성 로컬 환경에서만 발생.

## 실제 HTTP 통과 항목

1. 비공개 로컬 Storage 버킷에 테스트 이미지 업로드.
2. anon/authenticated JWT로 권한 있는 구매 RPC 직접 호출 차단.
3. 두 회원 실제 비밀번호 로그인·각기 다른 세션 쿠키 발급.
4. 로그인 없는 구매 차단·정상 회원 세션 조회.
5. 300C 결제와 동일 요청 재전송: 영수증1건·차감1회.
6. 카드번호 직접 지정 차단.
7. 200C 랜덤 구매·지갑 정합성.
8. PvP 방 생성/참가/타인카드 차단/상대카드 사전 비노출/READY/결과/전적/중복READY 차단.
9. 완료 결과를 sync HTTP로 복원.
10. 관리자 실제 로그인 및 일반4+HIDDEN1 업로드·공개·기존 공개사진 보존.
11. 공개한5개 슬롯 조회 및 실제 서명 URL 이미지 다운로드200.
12. 관리자 중지·재개.
13. 하루 무료뽑기 재요청에서 동일 결과·보상 중복 없음.
14. 돌보기 첫행동+일일퀘스트 합계20C.
15. 방문 신청·대기 중 재신청 중복 방지·관리자 승인30C. 실제09~21 KST 구간 실행.
16. 서로 다른 동시 구매2건은 잔액300C 중1건만성공·1건409; 동일 요청 동시2건은 양쪽200·영수증1건·추가차감없음. 제3자 PvP 접근 차단.
17. 로컬 합성 heartbeat를7초/31초 전으로 설정해 HTTP sync: 양쪽READY초기화/유예초과취소, 추가전적없음.

## 배포 적용 준비 (아직 미실행)

사용자 최종 운영배포 승인 후에만 아래 순서 적용한다.

- 기존 운영코드 SHA `6e81eb7581fd19d451c49055fd1a41c47820b298`와 후보 브랜치 차이 확인. GitHub main을 그대로 배포하지 않음.
- 기존 데이터 재조회 및 2→3→4→5 SQL 순서 준수. 운영의 기존 `coins=200` 제약은 4차 SQL로 `IN(200,300)` 교정 필요. 2차의 슬롯 가드는 제거 금지.
- 서버/공개 플래그 쌍: STAGE1_COINS, STAGE2_OFFICIAL, STAGE4_STORE, STAGE5_PVP를 활성화. 과거 STAGE3_PVP 플래그만으로 새 PvP가 켜지지 않음.
- 빌드/배포 확인 후 회원 로그인·카드조회·코인조회 등 운영에서 비파괴 확인. 실제 이용자 결제/사진 삭제를 스모크 테스트로 실행하지 않음.
- 백업 부족은 사용자 수락 예외이며 PASS가 아님. 동일 DB 내11/15 복구 사본은 최신 회원20명을 모두 포함하지 않고 원본사진 별도 아카이브도 없음. 코드 롤백과 데이터 완전복구는 구별.

## 확인 범위의 한계

실제 Google OAuth 제공자의 로그인 완료, 실제 휴대폰 카메라·진동, 모든 Figma 상태의 raster 차이0은 확인하지 않았다. 이번 검증은 합성 회원/사진과 실제 로컬 서비스의 HTTP 통합이며, managed Supabase와 버전/인프라가 완전히 동일하다는 뜻은 아니다. UI 제품 변경은 없고 기존 주요 화면 모바일 검증 결과를 유지한다.

이 보고서는 기존 문서의 “실제HTTP미검증” 상태를 위 로컬 범위에 한해 대체한다. 운영배포 승인 전 배포/운영마이그레이션 금지.
