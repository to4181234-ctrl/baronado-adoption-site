# 멍멍GO 최신 음원·UI 적용 기록 — 2026-11-03

## 소스 기준

최신 GitHub main에서 이어간다. 이번 변경의 시작 커밋은 7f9d686이다. 음원 ZIP의 과거 5차 코드·로컬 작업 제한 기록으로 소스를 되돌리지 않는다. 현재 사용자가 요청한 범위는 제공 효과음과 추가 UI 수정 및 배포다.

## 실제 전달된 음원

`baronado_audio_handoff_2026-11-03.zip` 안에 원본 SFX 19개가 있으며, 프로젝트의 파일과 모두 SHA-256 일치한다. PREVIEW 4개는 참고용이므로 공개 폴더와 앱 호출에 포함하지 않았다. 새 음원 생성·변환·외부 원곡 다운로드를 하지 않았다.

최종 선정 BGM은 Pallet Town, Wild Pokémon Battle, Trainer Battle, Lavender Town 네 곡이다. 실제 BGM MP3는 ZIP에 포함되지 않았으며, 사용자가 후속 메시지에서도 의도적인 미포함임을 확인했다. 원곡을 내려받거나 배포에 추가하지 않았다.

- `lib/goMusicCatalog.js`에 네 곡의 파일명·대기 상태를 기록했다. 없는 파일을 요청하거나 다른 곡으로 대체하지 않는다.
- 기존 도감/카메라 BGM 2곡은 최신 선정에서 제외되어 공개 파일과 호출에서 제거했다.
- prebuild는 SFX 19개만 설치·검증한다. 옛 BGM 2개를 다시 설치하지 않는다.
- 현재 운영에서 재생 가능한 것은 제공된 SFX 19개이며, BGM은 파일 연결 대기다. Lavender Town의 정확한 위치도 아직 확정하지 않았다.

## 효과음 구현

첫 실제 터치/키 입력에서 공유 Web Audio context를 활성화하고, 미리 읽은 원본 MP3를 버퍼로 재생한다. 앞 소리를 중단하면서 다음 소리를 재생하던 구조를 제거했다. 결과 API 응답 이후에도 이미 활성화한 context로 결과음을 재생한다. 화면 이탈·음소거·비활성화 시 진행 중 소리와 예약 소리를 취소하며, 늦게 로드된 소리를 뒤늦게 몰아서 재생하지 않는다.

- 선택/해제/두 장 준비, 배틀 시작·등장·1.4초 충돌·서버 확정 결과에 원본 SFX 연결.
- 목줄 선택/발견은 서로 잘리지 않게 재생. 발견 완료 시 자동 짖기는 제거하고, 강아지 터치에서만 짖기 1→2→3 순환.
- 교감 액션 성공 시 해당 효과음, 목줄 촬영 버튼에서 셔터음.
- 카드 획득음은 서버가 새 카드 발급을 성공한 HTTP 201에만 재생. 재시도 HTTP 200에는 재생하지 않는다.
- 카드 보기·재생에는 등장 효과음을 사용하여 획득음과 구분한다.
- 기존 음원 버튼은 공통 설정 변경과 다른 탭의 설정 변경에 맞춰 동기화한다. 새로운 스피커 UI는 추가하지 않았다.

## 추가 UI 수정

배너 한 개일 때 점 숨김, ‘이 아이에게 / 필요한 가족’ 고정 줄바꿈, 멍기록 영역 위 여백, 소개 단독 탭 중앙 배치, 획득 강아지와 만나러가기 간격, 2차원 픽셀 움직임, 원본 전적 SVG 프레임 복원, 배틀 충돌·결과 연출 강화.

카메라 권한 안내는 유지하고 촬영 화면의 수집/도망 대화창을 제거했다. 음원 버튼은 왼쪽, 줌·목줄 촬영 버튼·가이드는 중앙 정렬한다. 가이드 공간의 실제 가로·세로 중 작은 값을 사용해 큰 1:1 정사각형을 배치하고, 목줄 버튼은 별도 행에 둔다.

## 검증과 한계

Node 테스트 74개 통과, Next.js 운영 빌드 통과, 제공 SFX 19개 해시 확인 통과. 오디오 테스트는 사용자 제스처 전 무재생, 앞 소리 보존, 비동기 서버 결과음, 로딩 중 이탈 취소, 음소거·비활성·예약 취소와 빠른 중복 탭 방지를 확인한다.

실제 iPhone/Android 카메라 촬영·하드웨어 음량과 Instagram 내부 브라우저 청취 검증은 원격 브라우저 검사와 구분한다. BGM 네 곡은 파일 미제공 상태이므로 적용 완료로 보고하지 않는다.

개발 검증 시 `?audioDebug=1`을 붙이면 성공적으로 시작된 SFX 이름만 브라우저 debug 로그에 기록한다. 개인 정보·계정·쿠키는 기록하지 않는다.
