# 바로나도 입양 사이트

바로나도 애견카페에서 임시보호 중인 강아지들의 입양을 장려하고, 상주견을 소개하기 위한 사이트입니다.  
사용자 페이지와 관리자 페이지가 포함되어 있고, Supabase에 강아지 정보를 등록하면 사용자 페이지에 자동으로 반영됩니다.

## 페이지 구조

- `/` : 가족을 찾아요 리스트 페이지
- `/residents` : 상주견 소개 리스트 페이지
- `/dogs/[id]` : 강아지 상세 페이지
- `/admin` : 관리자 리스트 페이지
- `/admin?category=resident` : 상주견 관리자 리스트 페이지
- `/admin/new` : 강아지 등록 페이지
- `/admin/edit/[id]` : 강아지 수정 페이지

## 포함 기능

- 가족을 찾아요 / 상주견 소개 카테고리 분리
- 강아지 리스트 노출
- 등록된 게시글이 없을 때 빈 상태 화면 노출
- 입양 완료 체크 및 썸네일 오버레이 표시
- 상세 페이지 이미지 화살표 슬라이드
- 사진 클릭 시 크게 보기
- 모바일 드래그/스와이프 이미지 넘김
- 관리자 등록/수정/삭제
- 사진 업로드 최대 3장
- Supabase Database + Storage 연동

## 최근 수정

- 입양 완료되지 않은 게시글을 먼저 보여주고, 입양 완료 게시글은 리스트 하단에 표시되도록 정렬을 변경했습니다.
- 각 그룹 안에서는 최신 등록순으로 표시됩니다.

## 멍멍GO (2026-10-27 업데이트)

- `/go`: 입양 전/후 멍멍 도감. 상단 회원가입/로그인, 닉네임, 로그아웃.
- `/go/[id]`: 멍멍이별 내 카드. 카메라 전용 촬영, 하단 중앙 촬영 버튼. 자동 누끼 및 ML 의존성 제거.
- `/go/community`: 모두의 도감 게시판. 제목/내용/멍멍이/닉네임 검색, 최신순/오래된순. 월별 바로나도 pick 최대 3개.
- `/go/posts/[id]`: 개별 게시물. 카드에는 영문 로고, 멍멍이 이름, 촬영 날짜, 닉네임만 표시. 제목/기록/좋아요/신고/삭제는 카드 바깥에 표시.
- `/admin/go`: 승인/반려(사유 선택 + 기타 직접 입력), 공개 게시물, 반려 게시물, 월별 pick 선택, 게시물 통계.
- pick은 한국 시간의 달을 기준으로 자동 전환됩니다. 사진/기존 계정/좋아요/기존 설명은 보존됩니다. 기존 게시물에 제목만 추가합니다.
- 비밀번호는 4자 이상, 닉네임 중복확인은 등록 시 다시 검증합니다. 기존 비밀번호는 그대로 사용할 수 있습니다.
- 개인정보는 공개 API에 노출하지 않습니다. 계정 복구는 이메일 인증번호 방식으로 준비되어 있고, 기존 회원은 로그인 후 상단 닉네임을 눌러 이메일을 연결할 수 있습니다. 6자리 인증번호는 5분 후 만료, 최대 5번 시도, 인증 완료 기록은 한 번만 사용할 수 있습니다. 비밀번호 재설정은 기존 로그인 세션을 무효화합니다.

### 인증메일 발송 설정 (아직 외부 발신 서비스 연결 필요)

Resend에서 본인 소유 발신 도메인을 인증하고, Vercel 프로젝트의 Production/Preview 환경변수에 직접 등록합니다. 비밀 키를 코드나 채팅에 붙이지 마세요.

- `RESEND_API_KEY`: 발송 전용 권한의 API 키
- `GO_MAIL_FROM`: 인증된 도메인의 발신 주소 (예: `멍멍GO <no-reply@your-domain>`)

설정 뒤 재배포하면 이메일 인증과 신규 회원가입이 활성화됩니다. 설정 전에는 기존 회원의 닉네임 로그인이 유지되고, 인증메일 발송/신규 가입은 준비 중으로 표시됩니다. 복구용 이메일을 연결하지 않은 기존 계정은 이메일 인증 복구를 이용할 수 없으므로 먼저 연결해야 합니다. 실제 이메일 발송은 서비스 설정 후 별도 확인이 필요합니다.

### 데이터베이스

추가 마이그레이션: `supabase/migrations/20261027104818_go_board_and_email.sql`.
카드/계정/인증번호/월별 pick 테이블은 RLS 및 서버 역할 전용 권한을 유지합니다. 통계 및 검색 뷰는 `security_invoker`이며 공개 DB 접근을 허용하지 않습니다. 기존 관리자 환경변수와 서비스 역할 키는 서버에서만 사용합니다. 인증번호 기록은 해시로 저장되며 24시간 이전 기록은 다음 발송 요청 때 정리됩니다.
