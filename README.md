# 바로나도 입양 사이트

바로나도 애견카페에서 임시보호 중인 강아지들의 입양을 장려하고, 상주견을 소개하기 위한 사이트입니다.  
사용자 페이지와 관리자 페이지가 포함되어 있고, Supabase에 강아지 정보를 등록하면 사용자 페이지에 자동으로 반영됩니다.

## 페이지 구조

- `/` : 가족을 찾아요 리스트 페이지
- `/residents` : 상주견 소개 리스트 페이지
- `/dogs/[id]` : 강아지 상세 페이지
- `/admin` : 관리자 리스트 페이지
- `/admin?category=resident` : 상주견 관리자 리스트 페이지
- `/admin/new` : 강아지 등록 페이지
- `/admin/edit/[id]` : 강아지 수정 페이지

## 포함 기능

- 가족을 찾아요 / 상주견 소개 카테고리 분리
- 강아지 리스트 노출
- 등록된 게시글이 없을 때 빈 상태 화면 노출
- 입양 완료 체크 및 썸네일 오버레이 표시
- 입양 상태 필터(전체보기/입양 전/입양 완료)와 그룹별 최신순/오래된 순 정렬
- 바로나도 캐릭터를 사용한 첫 목록 로딩 화면(움직임 줄이기 설정 지원)
- 기준일과 당시 추정 나이로 계산하는 선택형 나이 표시, 보호소 이름·홈페이지 표시
- 상세 페이지 이미지 화살표 슬라이드
- 사진 클릭 시 크게 보기
- 모바일 드래그/스와이프 이미지 넘김
- 관리자 등록/수정/삭제
- 사진 업로드 최대 3장
- Supabase Database + Storage 연동

## Supabase 업데이트

새 프로젝트를 처음 만들 때는 전체 스키마 파일을 사용합니다.

```txt
supabase/schema.sql
```

실행 위치:

```txt
Supabase → SQL Editor → New query → schema.sql 내용 붙여넣기 → Run
```

기존 운영 프로젝트에는 전체 스키마를 재실행하지 말고 `supabase/add-profile-fields.sql`의 컬럼 추가 구문만 적용하세요. 기존 정책과 데이터가 유지됩니다.

## Vercel 환경변수

```bash
NEXT_PUBLIC_SUPABASE_URL=Supabase Project URL
NEXT_PUBLIC_SUPABASE_ANON_KEY=Supabase anon public key
```

## 최근 수정

- 입양 완료되지 않은 게시글을 먼저 보여주고, 입양 완료 게시글은 리스트 하단에 표시되도록 정렬을 변경했습니다.
- 각 그룹 안에서는 최신 등록순으로 표시됩니다.

## 나이·보호소·상세글 편집

기존 데이터베이스에 추가 컬럼이 없어도 나이·보호소·구조화된 소개를 사용할 수 있습니다. 저장 시 새 컬럼이 없다는 응답을 받은 경우에만 기존 `description` 끝에 앱 전용 메타데이터를 덧붙이고, 화면에서는 분리해 표시합니다. 기존 소개글 원문은 그대로 보존합니다. 추후 `supabase/add-profile-fields.sql`을 적용하면 다음 편집부터 전용 컬럼으로 저장됩니다.

자동 나이는 기준일 당시의 **추정 만 나이(정수)**를 바탕으로 기준일을 기념일처럼 계산합니다. 예를 들어 기준일에 2살로 안내받았으면 그날은 `약 2살 0일 추정`, 다음날은 `약 2살 1일 추정`으로 표시합니다. 기준일 및 당시 안내 나이는 상세 화면에 별도로 남습니다. 추정 범위나 개월 수 등 숫자 한 개로 표현하기 어려운 경우에는 자동 업데이트를 끄고 기존 나이 문구를 사용하세요.

목록에는 `약 2살 추정`처럼 연 단위까지만 표시하고, 경과 일수는 상세에서만 표시합니다. 관리자에서는 견종부터 잘 어울리는 가족까지 고정 질문 10개와 추가 질문·답변을 편집할 수 있습니다. 기존 공개 게시글의 원문과 일치하는 경우에만 `lib/curated-stories.js`의 항목별 교정본을 보여줍니다.

현재 저장소의 관리자 쓰기 정책은 익명 사용자도 허용합니다. 관리자 인증과 쓰기 권한은 별도로 점검해야 합니다.
